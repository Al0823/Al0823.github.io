**Key Features:**  
1. **CRUD Operations**:  
   - **Create**: POST with `tag=add` uses autonumber for ID  
   - **Read**: [search] with `cn` (contains) for name/email filtering  
   - **Update**: `tag=replace` with `eqid` for exact record matching  
   - **Delete**: POST with `tag=delete` and confirmation dialog  

2. **Database Structure**:  
   Requires `members.db` with fields:  
   - id (autonumber)  
   - name, email, membership  

3. **Search Functionality**:  
   Live search with `cn` (contains) operator for both name and email  

4. **Edit Flow**:  
   Clicking "Edit" loads form with pre-filled data via `?tag=edit&id=XXX`  

5. **Security**:  
   - Delete confirmation dialog  
   - Direct database operations only on exact ID match  

**To Use:**  
1. Create `members.db` with required fields  
2. Save as `members.dna` in WebDNA server directory  
3. Access via `http://yourserver/members.dna`  
4. First load will show empty list (add members via form)
