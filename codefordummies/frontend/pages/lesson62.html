JavaScript Scope



In JavaScript, "scope" determines where variables are accessible in your code.

There are two main types of scope:


Global Scope


A variable declared outside any function or block has **global scope**. It can be accessed anywhere in your code.




Local Scope / Function Scope


A variable declared inside a function has **local scope** (function scope). It is only accessible inside that function.




Block Scope


Variables declared with let or const inside a block ({}) have **block scope**. They are not visible outside that block.




var vs let / const in Loops


When using var in a loop, the variable is **function scoped** and affects the variable outside the loop. When using let or const, the variable is **block scoped** and does not affect the outer variable.

Nested Functions and Scope


Inner functions can access variables of outer functions (lexical scope), but outer functions cannot access variables inside inner functions.




Summary


  • Global scope: variables accessible anywhere.
  • Function scope: variables declared inside a function, accessible only in that function.
  • Block scope: variables declared with let or const inside a block, accessible only inside that block.
  • var vs let/const: var is function scoped, let/const are block scoped.
  • Nested functions: inner functions can access outer variables, but outer functions cannot access inner variables.


Understanding scope is essential to avoid variable conflicts and unexpected behavior in JavaScript.
