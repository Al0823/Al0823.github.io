JavaScript 2009 (ES5)



ECMAScript 5 added many features to make JavaScript easier and more powerful for developers. It introduced "strict mode", enhanced object handling, JSON support, and new array methods.


ECMAScript 5 (2009)


ECMAScript 2009 is also known as ES5.

It improved JavaScript by adding features that are still widely used in modern development today.


ES5 Features


  • "use strict" (Enables strict mode to catch common coding mistakes)
  • JSON methods (Parse and stringify JavaScript objects)
  • New Array methods (forEach, map, filter, reduce, every, some)
  • Object methods (Object.create, Object.defineProperty, Object.keys)
  • Getter and Setter properties
