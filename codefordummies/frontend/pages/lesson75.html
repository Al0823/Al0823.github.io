Logical Operators



Logical operators are used to determine the logic between variables or values.

They are commonly used in conditional statements to combine multiple conditions.

Logical operators return true or false.


The Logical AND (&&)


The logical AND operator (&&) returns true if both conditions are true.

If one condition is false, the result is false.




In the example above:

(x < 10 && y > 1) returns true because both conditions are true.

(x < 10 && y < 1) returns false because one condition is false.


The Logical OR (||)


The logical OR operator (||) returns true if at least one condition is true.

It only returns false if both conditions are false.




In the example above:

(x == 5 || y == 5) returns false because neither condition is true.

(x == 6 || y == 0) returns true because one condition is true.

(x == 0 || y == 3) returns true because one condition is true.


The Logical NOT (!)


The logical NOT operator (!) is used to reverse a boolean value.

If the value is true, it returns false.

If the value is false, it returns true.




In the example above:

!(x === y) returns true because x is not equal to y.

!(x > y) returns false because x is greater than y.


Combining Logical Operators


You can combine logical operators to create more complex conditions.

JavaScript evaluates logical expressions from left to right.

You can use parentheses to control the order of evaluation.




In this example, both conditions must be true:

The person must be 18 or older.

The person must have a license.


Short Circuit Evaluation


Logical operators use short-circuit evaluation.

For AND (&&): If the first condition is false, JavaScript does not check the second condition.

For OR (||): If the first condition is true, JavaScript does not check the second condition.

This improves performance and prevents unnecessary evaluations.
