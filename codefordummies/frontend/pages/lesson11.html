Arithmetic



Arithmetic in JavaScript lets you perform math operations on numbers. It includes basic math like addition and subtraction, as well as more advanced operations.

Arithmetic is used everywhere in programming, from simple counters to complex calculations.

JavaScript supports multiple arithmetic operators that work with numbers and sometimes strings.


Arithmetic Operators


JavaScript provides several arithmetic operators:




Addition (+) adds numbers together.

Subtraction (-) removes one number from another.

Multiplication (*) multiplies numbers.

Division (/) divides numbers.

Modulus (%) returns the remainder of a division.

Exponentiation (**) raises a number to a power.


Arithmetic with Strings


The + operator can also combine strings:




If you use + with a number and a string, JavaScript converts the number to a string:




Other operators like -, *, and / will try to convert strings into numbers.


Increment and Decrement


Increment (++) increases a number by 1.

Decrement (--) decreases a number by 1.




These can be placed before or after the variable:




When used before the variable, the value is incremented first.

When used after the variable, the original value is used first.


Operator Precedence


Operator precedence defines the order in which operations are performed.

Multiplication and division are done before addition and subtraction:




You can use parentheses to change the order:




Parentheses have the highest priority.

Exponentiation is evaluated before multiplication and division.


Assignment Arithmetic Operators


JavaScript also supports combined arithmetic and assignment operators:




These operators make code shorter and easier to read.

They are commonly used in counters and loops.
