JavaScript Const



A "const" in JavaScript is used to declare variables that cannot be reassigned. Once a value is assigned to a const variable, it cannot be changed later.

Const variables must be assigned a value when they are declared. They are block-scoped and behave differently from var.


Declaring Const


Const variables are declared using the const keyword.

They must be initialized at the time of declaration.




You cannot declare a const without a value. This will cause an error:




Cannot Be Reassigned


Const variables cannot be reassigned after declaration. Trying to assign a new value will cause an error.




Const does not mean the value is completely immutable. It means the variable identifier cannot be reassigned.


Block Scope


Const is block-scoped, meaning it only exists inside the block where it is defined. This includes loops, functions, and conditionals.




Const Arrays


You cannot reassign a const array, but you CAN modify its contents.




Const Objects


Const objects work the same way as arrays. You cannot reassign the object, but you can change properties.




Const vs Let vs Var


Use const when the value should not be reassigned. Use let when the value may change. Avoid var in modern JavaScript.




Must Be Assigned


Const variables must be assigned when declared. This is different from let and var, which can be declared first and assigned later.




When to Use Const


Always declare variables with const unless you know the value will change. This helps prevent accidental reassignment and makes code easier to understand.

Use const when:

• Declaring arrays
• Declaring objects
• Fixed values like PI
• Function references

Using const by default is considered a best practice in modern JavaScript.


Redeclaring Const


You cannot redeclare const variables in the same scope.




However, you CAN use the same name in different blocks.




Hoisting


Const is hoisted, but not initialized. This means you cannot use it before declaration.




This is known as the Temporal Dead Zone (TDZ), where the variable exists but cannot be accessed yet.
