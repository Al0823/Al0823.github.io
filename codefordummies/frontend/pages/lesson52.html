Set Methods



JavaScript Sets come with built-in methods that let you add, remove, check, and loop through values easily.

These methods help you manage unique collections without worrying about duplicates.


Common Set Methods


  • add() — Add a value
  • delete() — Remove a value
  • has() — Check if value exists
  • clear() — Remove all values
  • forEach() — Loop through values
  • values() — Get iterator of values
  • keys() — Same as values()
  • entries() — Returns [value, value] pairs

Summary


Sets are great when you need:
  • Unique values
  • Fast existence checks
  • No duplicates automatically
  • Simple iteration
Unlike arrays, Sets prevent duplicates by design and provide efficient lookup methods.
