Syntax



JavaScript syntax is the set of rules that define how JavaScript programs are constructed.

It describes how variables, functions, statements, and expressions must be written so the browser can understand and run your code.


JavaScript Values


JavaScript syntax defines two types of values:

  • Fixed values (Literals)
  • Variable values (Variables)

JavaScript Comments


Comments are used to explain code and are ignored by JavaScript.

Single-line comments start with //




Multi-line comments start with /* and end with */

JavaScript Identifiers


Identifiers are names used for variables, functions, and objects.

Rules for identifiers:

  • Names can contain letters, digits, underscores, and dollar signs
  • Names must begin with a letter
  • Names can also begin with $ and _
  • Names are case sensitive
  • Reserved words cannot be used as names


JavaScript Character Set


JavaScript uses the Unicode character set.

Unicode covers (almost) all the characters, punctuation, and symbols in the world.
