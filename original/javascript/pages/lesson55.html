Typeof



The typeof operator returns a string indicating the type of the unevaluated operand. It is useful to check the data type of a variable, constant, or expression in JavaScript.


Syntax


typeof operand

Typeof Returns a String


The typeof operator always returns a string, such as "number", "string", "boolean", "object", "function", or "undefined".


Common Uses


You can use typeof to:


  • Check the type of a variable before performing operations
  • Verify that a function parameter has the expected type
  • Detect undefined variables

Typeof Summary


  • typeof 42 → "number"
  • typeof "Hello" → "string"
  • typeof true → "boolean"
  • typeof undefined → "undefined"
  • typeof null → "object"
  • typeof {} → "object"
  • typeof [] → "object"
  • typeof function() {} → "function"
