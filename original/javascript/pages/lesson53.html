Maps



Map is a special type of object that holds key-value pairs. Unlike regular objects, Map keys can be any type—numbers, strings, objects, or even functions.

Maps remember the original insertion order of keys, making them useful when order matters.


How to Create a Map


You can create a JavaScript Map by:

  • Passing an array of key-value pairs to new Map()
  • Create an empty map and use set() to add entries
