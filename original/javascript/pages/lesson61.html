JavaScript Errors



Errors in JavaScript are problems in your code that prevent it from running correctly.

Errors are usually divided into three main types: Syntax errors, Runtime errors, and Logical errors.

Understanding errors is essential for debugging and writing working code.


Syntax Errors


Syntax errors occur when the code violates the rules of JavaScript syntax.

These errors prevent the code from running at all.

Common causes include missing parentheses, missing brackets, or typos.




In the example above, the missing closing parenthesis after x will cause a syntax error.

Syntax errors must be fixed before the code can run.


Runtime Errors


Runtime errors occur while the code is running.

These happen when the code encounters something it cannot process.

Examples include calling a function that does not exist or accessing a variable that is not defined.




In the example above, y is undefined.

Accessing y.length will cause a runtime error.


Logical Errors


Logical errors do not stop the code from running, but the program produces incorrect results.

These are usually caused by mistakes in your algorithm or logic.




In the example above, the subtraction operator is used instead of addition.

The code runs without errors, but the result is wrong.


Handling Errors with try...catch


JavaScript provides a try...catch statement to handle runtime errors gracefully.

The try block contains code to test for errors.

The catch block contains code to execute if an error occurs.




In the example above, z is not defined.

Instead of crashing, the catch block handles the error and prints a message.


throw Statement


The throw statement allows you to create custom errors.

You can throw an exception if a condition is not met.




In the example above, a custom error is thrown if age is less than 18.

This can be useful for input validation or other checks.


finally Statement


The finally block contains code that will always run, regardless of whether an error occurred or not.

It is often used to clean up resources or perform final actions.




In the example above, the finally block executes after the catch block.

It ensures that important cleanup code always runs.


Error Object


When an error occurs, JavaScript creates an Error object with useful properties:

  • name the type of error (SyntaxError, ReferenceError, etc.)
  • message a description of the error

You can access these properties inside the catch block.
