Type Conversion



Type conversion in JavaScript is when you manually convert data from one type to another. JavaScript can also perform automatic conversion (type coercion) in certain situations.

There are two main types of conversion:


  • **Explicit Conversion** – You convert the data yourself using functions like Number(), String(), or Boolean().
  • **Implicit Conversion (Type Coercion)** – JavaScript automatically converts types when performing operations with mixed types.

Other Conversion Functions


Other useful conversion functions include:


  • parseInt() – Converts a string to an integer.
  • parseFloat() – Converts a string to a floating-point number.
  • toFixed() – Converts a number to a string with a specified number of decimals.




Summary


- Number(), String(), Boolean() are used for explicit conversion.
- JavaScript automatically converts types in operations (type coercion).
- parseInt(), parseFloat(), and toFixed() are common helpers for conversion.
- Invalid conversions return NaN.
