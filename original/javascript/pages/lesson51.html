Sets



Set is a special type of object that lets you store unique values of any type—whether primitive types (like numbers or strings) or objects.

Think of it as a collection where duplicates are automatically removed and order is mostly irrelevant (though insertion order is remembered when iterating).


How to Create a Set


You can create a JavaScript Set by:

  • Passing an array to new Set()
  • Create an empty set and use add() to add values
