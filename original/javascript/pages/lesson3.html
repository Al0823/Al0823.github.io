Outputs



JavaScript can "display" data in different ways. These are called outputs.

JavaScript has several methods to output data, depending on where and how you want to show it.


JavaScript Display Possibilities


JavaScript can display data using:

  • Writing into an HTML element (innerHTML)
  • Writing into the HTML output (document.write())
  • Writing into an alert box (window.alert())
  • Writing into the browser console (console.log())

Printing with JavaScript


JavaScript does not have a built-in print object or print methods.

The only exception is calling the browser print function using window.print().




This will open the browser’s print dialog.
