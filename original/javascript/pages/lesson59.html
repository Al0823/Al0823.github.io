Regular Expressions (RegExp)



A Regular Expression (RegExp) is a special pattern used to match character combinations in strings. In JavaScript, RegExp are objects and can be used with RegExp methods or string methods like match(), replace(), search(), and split().


Creating a RegExp


You can create a RegExp object in two ways:

  • Using a regular expression literal: /pattern/flags
  • Using the constructor: new RegExp("pattern", "flags")

RegExp Flags


Flags are optional parameters for pattern matching:

  • g – global search (find all matches)
  • i – case-insensitive search
  • m – multiline search
  • s – allows dot . to match newline characters
  • u – full Unicode support
  • y – sticky search (matches from lastIndex only)

String Methods Using RegExp


Several string methods accept RegExp as parameters:


  • match() – returns all matches in a string
  • replace() – replaces matched patterns
  • search() – returns the index of the match
  • split() – splits the string by matches

Character Sets and Ranges


Character sets allow you to match one character from a set or range:


  • [abc] – matches a, b, or c
  • [0-9] – matches any digit
  • [^abc] – matches any character except a, b, or c

Metacharacters


Common metacharacters used in RegExp patterns:


  • . – any character except newline
  • \d – any digit (0-9)
  • \D – any non-digit
  • \w – any word character (a-z, A-Z, 0-9, _)
  • \W – any non-word character
  • \s – whitespace character
  • \S – non-whitespace character
  • \b – word boundary
  • \B – non-word boundary
  • ^ – start of string
  • $ – end of string
  • * – 0 or more occurrences
  • + – 1 or more occurrences
  • ? – 0 or 1 occurrence
  • {n} – exactly n occurrences
  • {n,} – n or more occurrences
  • {n,m} – between n and m occurrences
