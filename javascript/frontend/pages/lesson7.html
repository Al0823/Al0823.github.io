Variables



Variables in JavaScript are containers for storing data values. They allow you to give a name to a value so that you can use and manipulate it later.

Variables can hold numbers, strings, booleans, objects, arrays, or any other type of data.

They are fundamental for building dynamic programs and for keeping track of information.


Declaring Variables


JavaScript provides three ways to declare variables: var, let, and const.


Using var


var declares a variable, optionally initializing it to a value.

Variables declared with var have function scope and can be redeclared and updated.




Using let


let declares a block-scoped variable. You can update it, but you cannot redeclare it in the same scope.

Block scope means the variable only exists inside the block, statement, or expression where it is used.




Using const


const declares a block-scoped variable that **cannot** be updated or redeclared.

A const variable must be initialized at the time of declaration.




Variable Names


Variable names (identifiers) in JavaScript must follow these rules:

- Can contain letters, digits, underscores, and dollar signs.
- Must begin with a letter, underscore (_), or dollar sign ($).
- Cannot be a reserved keyword (like for, let, if, etc.).
- Are case-sensitive (myVar and myvar are different).

Data Types


Variables can store different types of data, including:

- Number: let age = 30;
- String: let name = "Alice";
- Boolean: let isActive = true;
- Array: let colors = ["red","green","blue"];
- Object: let person = {firstName:"Alice", age:25};
- Undefined: let data; (no value yet)
- Null: let data = null; (intentional empty value)

Hoisting


Variables declared with var are "hoisted" to the top of their scope, meaning you can reference them before they are declared (though the value will be undefined).

Variables declared with let and const are also hoisted, but cannot be accessed before declaration (this is called the "temporal dead zone").




Best Practices


- Use let by default for variables that will change.
- Use const for constants that should not change.
- Avoid using var unless necessary for older browser support.
- Give meaningful names to variables to make code readable.
- Declare variables as close as possible to where they are used.
