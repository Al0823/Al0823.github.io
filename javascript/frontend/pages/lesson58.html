Bitwise Operators



Bitwise operators perform operations on **binary representations** of numbers. Each number is converted to a 32-bit binary format, the operation is applied bit by bit, and the result is converted back to a decimal number.


Bitwise AND (&)


The AND operator returns 1 only if **both bits are 1**. Otherwise, it returns 0.




Bitwise OR (|)


The OR operator returns 1 if any of the bits are 1.




Bitwise XOR (^)


The XOR operator returns 1 if the bits are different, otherwise 0.




Bitwise NOT (~)


The NOT operator inverts all bits. It is equivalent to -(x+1) for signed 32-bit numbers.




Left Shift (<<)


Shifts the bits to the left and fills the right with zeros. Equivalent to multiplying by 2 for each shift.




Right Shift (>>)


Shifts the bits to the right and keeps the sign bit (preserves the sign for negative numbers). Equivalent to dividing by 2 for each shift.




Zero-fill Right Shift (>>>)


Shifts the bits to the right and fills the left with zeros. Always returns a positive number.
