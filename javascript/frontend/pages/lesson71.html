JavaScript 1999 (ES3)

JavaScript ES3 added many things to aid the average user, such as Regular expressions, Error handling (try...catch), the switch keyword, and the do...while loop.

ECMAScript 3 (1999)

The first revision to JavaScript.
ECMAScript 1999 is also known as ES3.
Despite its age, it is still supported by all modern browsers today.

ES3 Features

  • Regular expressions
  • Error handling (try...catch)
  • The switch keyword
  • The do...while loop
