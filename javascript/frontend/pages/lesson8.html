Let



The let keyword was introduced in ES6 (2015) and is used to declare variables in JavaScript.

Variables declared with let are block scoped, which makes them safer and more predictable than older variable declarations.

Unlike var, let prevents accidental redeclaration and limits where a variable can be used.

Block Scope


The biggest difference between let and var is block scope.

A block is anything inside curly braces {} (like loops or if statements).

Variables declared with let only exist inside the block they are created in.

Let vs Var


Before ES6, var was the only way to declare variables.

Var has function scope, while let has block scope.






Let in Loops

Hoisting


Variables declared with let are hoisted, but NOT initialized.

This means you cannot use them before declaring them.




This is called the Temporal Dead Zone — the time between entering scope and declaration.


Global Scope


Variables declared with let in the global scope do NOT become part of the window object.




This makes let safer than var for modern applications.


When to Use Let


Use let when:

• The variable value will change

• You want block scope safety

• You want to avoid redeclaration bugs

For constants, use const instead.
